## 📌 About

This is my personal portfolio built with pure HTML and CSS — no frameworks, no build tools, just clean, fast, and fully responsive code. It features a cyberpunk / terminal-inspired design with a dark theme, scanline overlay, and animated elements.

---

## ✨ Features

- **Responsive Design** — works on mobile, tablet, and desktop
- **Terminal UI** — interactive terminal block in the contact section
- **Animated Hero** — fade-in text, glowing accents, blinking cursor
- **Skill Bars** — visual proficiency indicators
- **Cert Cards** — completed certification showcase with animated glow badge
- **Project Showcase** — live project card with tech stack breakdown
- **Mobile Hamburger Menu** — smooth drawer navigation for small screens

## 🚀 Run Locally

No setup needed — just open the file in a browser:

```bash
git clone https://github.com/madhav-nangliya/portfolio.git
cd portfolio
# open index.html in your browser
```

Or with a local server:

```bash
npx serve .
# or
python -m http.server 8000
```
